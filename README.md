# Team Task Manager

## Overview
This is a full-stack web application for managing team tasks. It includes features such as authentication, project and team management, task assignment and tracking, and a dashboard for monitoring progress.

## Features
- **Authentication**: Signup/Login functionality.
- **Project & Team Management**: Create and manage projects and teams.
- **Task Management**: Create, assign, and track tasks.
- **Dashboard**: View tasks, statuses, and overdue items.
- **Role-Based Access Control**: Admin and Member roles with specific permissions.

## Requirements
- **Backend**: REST APIs with a database (SQL/NoSQL).
- **Frontend**: User-friendly interface.
- **Validations**: Proper input validations and relationships.
- **Access Control**: Role-based access control.

## Getting Started
1. Clone the repository.
2. Install dependencies for both backend and frontend.
3. Set up the database.
4. Run the development servers.

## Folder Structure
- `backend/`: Contains the backend code (APIs, database models, etc.).
- `frontend/`: Contains the frontend code (React components, styles, etc.).
- `docs/`: Documentation and resources.
